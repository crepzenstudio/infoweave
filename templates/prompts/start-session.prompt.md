# Session Start — Orientation Checklist

You are starting a new session. Execute these steps in order before doing any work:

1. **Read the rulebook** — read `AGENTS.md` in full. Note the read order and safety rules.

2. **Load knowledge map** — read `knowledge/INDEX.md`. Identify categories relevant to the user's likely request.

3. **Load last handoff** — read `handoffs/_latest.md` (if it exists). Summarize in one sentence what the previous session left unfinished.

4. **Load current focus** — read `memory/current-focus.md`. Note the active phase and next steps.

5. **Load preferences** — read `memory/preference.md` (if it exists). Apply the user's language, tone, and autonomy settings for this session.

6. **Report orientation** — tell the user in 2–4 lines:
   - What the last session was doing (from handoff/current-focus)
   - What knowledge categories are loaded and relevant
   - What you are ready to do next

Then wait for the user's instruction.

> **Note**: If none of the files above exist yet, the workspace is being set up for the first time.
> Read `README.md` and offer to run the interactive bootstrap interview.
